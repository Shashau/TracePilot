WINDOWS (recommended presentation setup)
1. Install Python 3.12, 64-bit/x64. Select Add Python to PATH.
2. Extract the ENTIRE ZIP into a writable folder.
3. Double-click START_WINDOWS.bat.
4. Dashboard: http://127.0.0.1:8000
5. REST API documentation: http://127.0.0.1:8000/docs

The ZIP includes all pinned Windows Python 3.12 x64 dependencies.
After Python is installed, Windows setup and the demo work offline.
The Python interpreter itself is not bundled.

MAC / LINUX
Open a terminal in this folder and run: bash start_mac_linux.sh
First setup on Mac/Linux needs internet. Uses the same package versions.
